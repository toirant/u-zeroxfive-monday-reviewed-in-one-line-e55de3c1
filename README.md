## The entry

> Monday: one star. The coffee was cold, the 9am could have been an email, and my inbox greeted me like a debt collector with a grudge.

## How it works

`main.ts` validates the line (one line, 1–200 characters, not only
whitespace), writes it to `/output/entry.txt`, then reads it back to
confirm what landed on disk matches exactly.

Run it with:

```sh
node main.ts
```
